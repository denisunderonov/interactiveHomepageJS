# Интерактивная домашняя страница

Персональная стартовая страница с виджетами: todo-лист, калькулятор и аудиоплеер.

## 🚀 Демо

https://denisunderonov.github.io/interactiveHomepageJS/

## Технологии

- HTML5, CSS3, JavaScript (ES6+)
- Webpack для сборки
- Spotify API для музыки
- LocalStorage для сохранения данных

## Функционал

- **Todo-лист** - создание и удаление задач
- **Калькулятор** - базовые математические операции
- **Аудиоплеер** - воспроизведение треков
- Сохранение данных между сессиями
- Модульная архитектура
